# 播放器设置与全屏选集

2026-11-17，承接[手机手势](player-gestures-20261117.md)。本次仅修改 Web；既有来源修复、七源暂停和超分停用保持，不增加视频代理。

## 使用方式

- 齿轮设置中的“画面与播放”提供画面亮度、视频音量、自动／4:3／16:9、填满画面、水平镜像、关灯模式和还原画面。
- 亮度为画面滤镜，范围 20%–200%，与左侧上下手势共用同一数值；不修改设备背光。设备拒绝网页音量写入时显示使用设备音量键的提示。
- 播完后可选择暂停、自动下一集或单集循环。默认暂停；最后一集没有下一集时正常结束。自动切集和手动选集都保留同一影片的播放器全屏容器。
- 手机全屏左上角新增退出全屏按钮。全屏控制栏的“选集”打开播放器内部侧栏，包含当前线路、集数和大于 50 集的范围选择；点击当前集继续播放并收起面板。
- 关灯遮罩只调暗播放器外的页面，点击遮罩开灯。支持画中画的浏览器会显示画中画动作。
- 画面和播完行为保存在本机 `ytv:player-settings`；原倍速、音量、静音偏好仍由现有偏好绑定拥有。
- 移除来源评价中的“每个来源计一票，可修改或撤回”；评价与撤回功能保持。

## 音量均衡与功能边界

提供关闭、标准和高动态。标准压缩较大声段，高动态保留更多强弱变化；属于当前视频的实时动态压缩，不是离线响度分析或转码。仅允许已由 hls.js 挂载、当前原生媒体地址为 Blob MediaSource 的音频进入 Web Audio。用户点击后先成功启动 AudioContext，再连接媒体；切集时释放该图并恢复未开启状态。直接跨域 MP4 和原生 HLS 路径不开放均衡，以免浏览器将不可读的媒体音频静音。

依据：[W3C Web Audio](https://www.w3.org/TR/webaudio/) 的媒体源跨域静音约束。直接播放、视频分片和音频均不经本站视频代理。

编码选择需要上游提供真实的不同编码版本，本次没有添加 AV1／HEVC／AVC 假开关。现有来源不提供观看热度时间轴，也不展示“高能进度条”开关。倍速、音轨和字幕继续由现有播放器设置提供，选项取决于当前媒体。

## 实现与验收入口

设置通过现有播放器皮肤的模板扩展入口接入。侧栏位于全屏容器内部，选择器关闭跨容器 Portal；设置输入隔离播放器快捷键。画面尺寸观察真实媒体容器，避免进入全屏后仍沿用页面小窗尺寸；菜单的全屏位置避免旧移动浏览器的弹层跑到视口之外。

一次性 CLI Playwright 和 MuMu 实际页面检查、制品身份与发布结果见 [验证回执](player-settings-20261117-verification.json)。长期恢复入口为产品 Flightdeck 的“电影体验与统一播放”Work。

未覆盖实体手机、iOS、整集时长、带真实字幕或多音轨媒体、已登录管理会话和本地 Workspace 组合。本轮使用生产等价候选与真实来源；不将浏览器手机视口或模拟器当作实体设备验收。
