# 来源五片抽样复审

## 接受标准

按用户最新要求：广告不是单独淘汰条件，实际画面达到高清水平可以接受；广告多且低清的样本淘汰。帧尺寸只是技术门槛，不能证明真实细节。1920 宽的宽银幕裁边素材单独记录其实际高度，不因裁掉黑边而误判为低清；低清放大也不能靠尺寸通过。

本轮优先近年电影、CG动画，每个重点来源选择五个不同片名。检查35秒、片长45%、片长85%三个时间点，记录实际解码尺寸、时长、广告和画面细节。不能把三个时间点都未见广告写成全片无广告；不能把接口可搜索写成播放可用。未成功出画的来源保留失败，不用目录的HD标签充数。
