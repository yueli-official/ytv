# 来源排序与前20入口复审（2026-10-24）

## 状态与口径

发布目标：20个启用入口，其中至少6个动漫入口有五部不同作品的高清实播证据。已正式发布 `ytv-source-top20-20261024-07`。公开接口已核对恰好20个启用来源，顺序与下表一致。

不是“全部来源全部校准成功”。原21源均做过五片尝试，但有搜索、解析、播放失败。本轮保留失败记录，追加近年作品和其他线路，不将补选后的五个成功样本写成首次成功率100%。画质按实际画面细节人工判断，1920×1080只作技术信息；不声称原生4K、全源高清、全片无广告或长期稳定。

排序综合抽样画质、出画情况、广告和重复入口；优先级仅为内部配置，不新增公开口碑分，也不制造用户评价票。前五项设管理员推荐，其余保留用户评价与徽标。下表排名是配置基础顺序，搜索结果仍可能受用户真实评价影响。
