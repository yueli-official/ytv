# 全候选来源五片审核（2026-10-24）

## 范围与结论口径

原目录69条接口中，39条为普通来源，30条为成人来源。普通39条全部执行五片搜索，共195个初始槽位；失败接口另按产品实际 `ac=videolist` 参数复试。成人30条遵照用户“不收成人”要求排除，不进行播放。另列既有11个Kazumi动漫来源，明确本轮复查与历史证据。69不是69个独立普通片库，镜像与聚合接口不能当独立资源量。

高清优先指实际画面清晰且达到1080档，不凭片名HD/4K或解码尺寸认定。宽银幕1920×800一类正常裁黑边不因高度不足1080否决；720源、枪版、竖画布中的小横片不能算高清。3840解码尺寸只记技术信息，不保证原生4K。

商业广告只计博彩、充值、招揽等推广；字幕组署名、制作名单、歌词翻译、片内剧情和正常台标不计。分开记开头/结尾少量推广、正片偶发推广、正片反复推广、全屏插片。高清但反复博彩需降级；低清且广告多排除。

每条成功媒体目标9个采样点：35秒、10%、25%、45%、45%+15秒、45%+30秒、65%、85%、97%。中段三个点用于确认至少30秒跨度的反复叠加，不是全片逐帧审查；未检出不等于全程无广告，不能据此计算广告持续总时长。失败帧保留。每源五部是目标，搜索/播放失败意味着质量未知，不编造五片通过。

本轮只是审核与建议，生产仍为07版20入口，未修改启用、推荐、用户票数或线上排序。
